## 目标

参与者逐渐学会“我这里发生变化 → 我的声音这样变化”，进而探索声音是否能被体验为自己的延伸。本轮先做可单独操作、可回放比较的音乐映射；听得出变化不等于已经证明自我归属或反思效果。

- 每次只改变一个音乐维度，找清楚可听、有方向、可重复的变化。
- 再用经过检查的真实特征驱动它。一个特征可以试听多个映射，最终不必全保留。
- 普通生理变化与“邀请重新考虑比较标准”的变化必须可区分；不能同时抢同一参数，也不能只靠界面标签说它们不同。
- 先读 AGENTS.md、git status 和最新代码；保留用户修改，不自动 commit/push。本轮要交付可试听的映射，不停在规划或重复完成 T18。

### M03：做六种可单独试听的音乐变化

先用同一低→中→高→低控制轨迹和手动控制，分别听到每个候选；再用同一段真人回放驱动它们。下面是声音候选，不是已经验证的心理状态映射。

| 候选只改变什么先固定什么 |                                           |                       |
| ------------ | ----------------------------------------- | --------------------- |
| level        | 平滑响度，保留为对照                                | 音高、音色、节奏、效果           |
| pitch        | 一条可辨声线的音高或音区，在现有 G Lydian 音集/范围内量化        | 和弦底座、音色、节奏、效果         |
| timbre       | 同一音高的泛音组权重；另可试听和弦内音符权重，二者分开命名             | 主音高与节奏；做适度响度补偿        |
| space        | 混响尾音/干湿，或可辨的延迟重复；reverb、delay 作为两种替代预设分别试 | 音高、节奏网格、基础音色          |
| harmony      | 少量明确 voicing 状态/和声路径，保留共同音与平滑连接           | 音区范围、音色、节奏、效果         |
| rhythm       | 固定 tempo 下量化的稀疏/密集起音，或预先列出的节奏型            | 音高、和声、效果；不用音量随机抖动冒充节奏 |

- 连续量需平滑；离散音高/和声/节奏用阈值回差和最短保持，避免在边界反复跳。节拍量化要列出新增等待时间，不能宣称零延迟。
- 变化范围可配置；不能大部分时间卡在两端，也不能为了“生动”加与输入无关的随机演化。
- 逐项展示实际控制量、改变的音乐参数和生效时间。音乐参数单位与 EEG 特征单位分开。
- 非 level 候选尽量接近响度，再人工判断是否主要只听到更响。亮度/音色、节奏/延迟天然可能听混，需要比较，不假定参数名不同就一定可辨。
- 干声始终可辨，效果尾音有界；delay feedback 不自激。切换、停止、断流仍须平滑且可停。保持持续节点，无逐帧新建 Synth。
- 九值 frame 与 invitation 合同保持不变；需要附加音乐控制时采用小而明确的独立扩展，不把新参数偷塞到 EEG 字段里。

### M04：给每条“数据→声音”配对留下依据

- 配置记录：特征/通道、公式、有效性、缩放、对应音乐参数、范围、延迟、来源和证据状态。不能把每个 descriptor 都当一个独立行为状态，也不把相近/相关特征硬分成多个心理状态。
- 当前真实静息记录可用来比较 F3 energy 等变化的听觉效果；可计算合格 EEG 的 alpha 等候选，但缺条件标签时只称“该频带变化”。不要自动打开全部九值。
- 后续有标签的睁闭眼可检验 P3/P4 alpha；安静默想/聆听、自然发音需要另录重复条件。F3/F4 theta、C3/C4 mu/beta 只是候选，需看实际结果后再决定配音高、音色或和声。
- Ch8 若用于节奏/包络，明确来源是肌肉活动；Ch7 不合格时禁用相关映射。身体输入可以辅助，不能拿它冒充 EEG 思考指标。
- 每个配对状态写为“手动试听 / 真人回放可用 / 行为对应待验证 / live 已验证”。不要求本轮用静息数据证明所有行为对应。

### M05：让 invitation 与上述变化分得开

- 继续使用独立 InvitationEvent 和 amount 包络、目标声部及拒绝/结束逻辑；没有 invitation event 时不执行邀请变化，不能由 EEG novelty 自动触发。
- 先把一种音乐变化族专留给 invitation。例如可试听保留低声部和共同音的短暂和声偏移/返回；仍由当前声部演奏，不另播提示音。“像自己的声音”仍待人听。
- 六个候选是菜单，不要求全部同时用。若 invitation 使用 harmony/上声部移动，就先从生理映射组合中关闭容易与它混淆的和声/上声部候选；也可试听后换一种专属方式。不得未经判断把同一个 pitch 动作分配给两个来源。
- 配置拒绝参数冲突；普通生理调制在其他维度继续进行。邀请结束回到当时应有的基线，不回到几秒前的旧快照。
- 渲染“仅生理变化 / 仅邀请 / 两者一起”的对照。能否辨认来源、是否仍像同一声部，必须保留人工结果，测试不能代答。

### M06：交付一套我能直接试听的东西

- 一条启动命令，说明 manual/replay/live 以及当前读哪个会话；本轮默认真人 replay，无需佩戴电极。提供切换候选、重复片段、触发/结束 invitation 的操作。
- 短的同输入对照音频、可追溯配置和一张映射表。不要让用户先听十几分钟日志，也不要让一次试听同时改变五种维度。
- 试听问题用人话：听出了哪种变化？何时开始？能否区分音高/音色/空间/节奏/邀请？是否持续像同一个声音？是否好听或疲劳？可将候选标签隐藏后做混淆记录。

- 回归只覆盖受影响的回放/时间、映射范围、身份/邀请、停止/节点和已有协议；保存实际通过/未通过情况，不扩展无关测试。
